# Ticketer

**ticketer.hitad.lk**

Comprehensive online ticketing and event management system.

---

## Access URLs & Portals

Base Domain: `https://ticketer.hitad.lk`

### 1. Admin Portal
* **Dashboard / Panel:** [https://ticketer.hitad.lk/admin](https://ticketer.hitad.lk/admin) (`/admin/dashboard`)
* **Dedicated Login:** [https://ticketer.hitad.lk/login/tkadmin](https://ticketer.hitad.lk/login/tkadmin)
* **General Login:** [https://ticketer.hitad.lk/admin/login](https://ticketer.hitad.lk/admin/login)

### 2. Organizer Portal
* **Dashboard / Panel:** [https://ticketer.hitad.lk/organizer](https://ticketer.hitad.lk/organizer) (`/organizer/dashboard`)

## Project Structure

* **`ticket-booking-system/`**: Backend Spring Boot REST API service.
* **`ticket-booking-admin/`**: Frontend React web application for Admin, Organizer, Organizer Employee, Gate Staff, and Customer ticketing.
